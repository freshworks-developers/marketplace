# React Meta frontend skeleton (Platform 3.0)

Default UI-only app: `metaConfig.framework: "react"`.

- **DEW 3.0 (required)** — `@freshworks/dew-components` + `@freshworks/dew-styles`
- **React Router** — `path="*"` home, `/app/...` feature routes
- **No Crayons**

```bash
npm install && fdk run
```

Optional: commented `vite.config.js`, `tailwind.config.js`, `postcss.config.js` — see `references/react-meta/`.
