# React Meta hybrid skeleton (Platform 3.0)

UI + SMI + external API via `$request.invokeTemplate`.

- **DEW 3.0 (required)** — `@freshworks/dew-components` + `@freshworks/dew-styles`
- **`{{{appclient}}}`** in `app/index.html` when using client SDK
- **No Crayons**

```bash
npm install && fdk run
```
