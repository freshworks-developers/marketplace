# Templates (assets)

Official **React Meta** layout and **`package.json`** / build config come from **`fdk create`** → **`react-starter-template`**.

Keep **migration** targets aligned with that template (dependencies, **`vitest`**, **`app/`** layout) when adding **`metaConfig`** to an existing app.

This folder holds **optional** skill-maintained snippets only—**not** a full app replacement for the FDK template.
